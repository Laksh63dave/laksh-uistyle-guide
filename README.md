
# Laksh Apple UI Guide

### A reusable design system for clean, premium, Apple-inspired web interfaces.

**Created by [Laksh Dave](https://github.com/Laksh63dave)**

Laksh Apple UI Guide is a reusable design system for building polished, intuitive, and visually consistent web interfaces.

Inspired by Apple's approach to simplicity and attention to detail, it provides practical guidelines for colour, typography, spacing, layout, components, interactions, motion, responsiveness, and accessibility.

It is designed to work across different types of digital products rather than being limited to a single website or template.

## What does it cover?

- **Colour system** — Neutral foundations, restrained accent colours, and consistent contrast.
- **Typography** — Clear hierarchy, readable text, and consistent type scales.
- **Spacing and layout** — Intentional whitespace, alignment, and responsive containers.
- **Components** — Buttons, cards, navigation, and interactive elements.
- **Product interfaces** — Dashboard previews, feature sections, and structured layouts.
- **Motion** — Subtle transitions, scroll animations, and interaction feedback.
- **Responsive design** — Adaptable layouts for desktop, tablet, and mobile.
- **Accessibility** — Readability, keyboard interaction, and reduced-motion support.

## Using the skill

This repository follows the Agent Skills format.

1. Download or clone this repository.
2. Place the skill folder in a location supported by your AI coding agent.
3. Make sure `SKILL.md` and the `references` folder remain together.
4. Ask your coding agent to use the Laksh Apple UI Guide when designing or refining a website.

The skill's `SKILL.md` contains the instructions, while the detailed design principles are documented in `references/design-system.md`.

## Example prompt

```text
Use the Laksh Apple UI Guide skill to design a premium,
responsive SaaS landing page.

Follow its design principles for typography, colour,
spacing, layout, components, and interactions.

Avoid generic AI-generated layouts and unnecessary
visual effects. Make every design decision intentional.
```

## Philosophy

A premium interface does not need more decoration. It needs better decisions.

The goal is to make every element feel intentional, every interaction feel natural, and every section contribute to a cohesive user experience.
